# Symbol и итераторы

**Определение.** `Symbol` — примитив, каждое значение которого уникально. Используется как ключ свойства, который не столкнётся с другими. Итератор — объект с методом `next()`, который возвращает `{ value, done }`. Итерируемый объект — тот, у которого есть метод `[Symbol.iterator]()`, возвращающий итератор.

## Symbol
- `Symbol('id')` всегда новый: `Symbol('id') !== Symbol('id')`. Описание нужно только для отладки.
- `Symbol.for('id')` берёт символ из глобального реестра по ключу: два вызова вернут один и тот же символ.
- Встроенные символы (`Symbol.iterator`, `Symbol.asyncIterator`, `Symbol.toPrimitive`) — точки, через которые движок вызывает твой код.

## Протокол итерации
`for...of`, спред `[...x]`, деструктуризация `const [a, b] = x` и `Array.from` вызывают `x[Symbol.iterator]()` и дёргают `next()`, пока не придёт `done: true`.

```js
class Bag {
  items = [1, 2, 3];
  *[Symbol.iterator]() {
    yield* this.items;
  }
}
[...new Bag()]; // [1, 2, 3]
```

- `*[Symbol.iterator]() { … }` — **объявление метода** с вычисляемым именем, а не вызов. Звёздочка делает его генератором. Вызывает его движок при `for...of`, спреде и деструктуризации.
- Метод объявляют в классе, а не вешают на экземпляр: иначе его нет у других экземпляров, и TS ругается на тип.

## Генераторы
- Вызов генераторной функции тело не выполняет, а возвращает объект-генератор. Он одновременно итератор (есть `next`) и итерируемый (его `[Symbol.iterator]` возвращает его самого).
- `next()` вызывает движок, когда генератор используется в `for...of` или спреде.
- `yield [1, 2, 3]` отдаёт один элемент — массив. `yield* [1, 2, 3]` отдаёт элементы по одному.
- `return x` попадает в `{ value: x, done: true }`. `for...of` и спред это значение игнорируют. Значение выражения `yield* inner()` — это `return` делегата.

```js
function* inner() { yield 1; return 'end'; }
function* outer() {
  const r = yield* inner(); // r === 'end'
  yield r;
}
[...outer()]; // [1, 'end']
```

## Частые ошибки понимания
- **«`*[Symbol.iterator]()` что-то вызывает».** Это объявление метода, вызывает его движок.
- **«`yield` и `yield*` одинаковы».** `yield` отдаёт значение целиком, `yield*` делегирует и отдаёт элементы по одному.
- **«`for...of` видит `return` генератора».** Нет, цикл заканчивается на `done: true` и это значение пропускает.
- **«`Symbol('x') === Symbol('x')`».** Нет. Одинаковые символы по ключу даёт только `Symbol.for`.

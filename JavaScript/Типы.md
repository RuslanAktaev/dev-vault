# Типы

**Определение.** В JS 8 типов: семь примитивов — `number`, `bigint`, `string`, `boolean`, `undefined`, `null`, `symbol` — и `object`. Функции и массивы — это объекты.

## Странности, которые надо знать
- `NaN` — не тип, а значение типа `number`: `typeof NaN === 'number'`.
- `typeof null === 'object'` — историческая ошибка, её оставили ради совместимости. Проверять `null` нужно через `=== null`.
- `typeof function () {} === 'function'`, хотя отдельного типа «функция» нет.
- Приведение к числу: `Number(null) === 0`, а `Number(undefined)` — `NaN`.

## bigint
- Только целые числа произвольной длины: `10n ** 30n`.
- Внутри это массив машинных слов переменной длины, арифметика делается программно, поэтому медленнее `number`.
- В арифметике с `number` не смешивается: `1n + 1` → `TypeError`. Сравнения разрешены: `1n < 2` → `true`, `1n == 1` → `true`, `1n === 1` → `false`.

## Частые ошибки понимания
- **«`NaN` — отдельный тип».** Это значение `number`.
- **«`null` — объект».** Это примитив, `typeof` врёт исторически.
- **«`null` и `undefined` приводятся одинаково».** К числу — `0` и `NaN`.
- **«bigint — просто большой number».** Отдельный тип: без дробей, без смешивания в арифметике, медленнее.

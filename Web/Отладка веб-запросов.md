# Отладка веб-запросов

**Ключевая идея.** Браузер многое делает молча: не прикладывает куку, не отдаёт ответ странице, не отправляет запрос после проваленного preflight. Ошибка в консоли часто описывает следствие, а причину нужно искать во вкладке Network и в заголовках. Для каждого шага полезно спрашивать себя: «что здесь запоминается и кто это проверяет».

## Чеклист

| Симптом | Куда смотреть |
|---|---|
| Старая версия файла | Network → заголовки ответа: `Cache-Control`, `ETag`, `Age`. Hard reload и «Disable cache». Кеш CDN |
| «CORS error» | Network → реальный статус ответа и сам preflight (`OPTIONS`). Заголовки `Access-Control-*`, `Vary: Origin` |
| Кука не ставится или не уходит | Application → Cookies. Предупреждение у `Set-Cookie`. `credentials`, `SameSite`, `Secure`, `Domain`, `Path` |
| 401 или 403 | 401 — не залогинен или токен просрочен. 403 — залогинен, но нет прав |
| Бесконечные редиректы за прокси | `X-Forwarded-Proto` и настройка доверия к прокси |
| Mixed content | Console: ресурс по `http://` на HTTPS-странице |
| `unable to get local issuer certificate` | Сервер не отдаёт промежуточный (intermediate) сертификат |
| OAuth `redirect_uri mismatch` | Посимвольное совпадение URI с настройкой у провайдера. `state` |
| OAuth `invalid_grant` на `/token` | `code_verifier` не совпал или потерялся между шагами. `code` уже использован или истёк |
| WebSocket не подключается | Network → WS: пришёл ли статус 101. Origin, idle timeout прокси |
| JWT «invalid» | Раскодировать токен и проверить `exp`, `aud`, `iss`, алгоритм |
| POST выполнился дважды | Ретраи клиента или прокси. Нужен `Idempotency-Key` |

## Частые ошибки понимания
- **Верить тексту «CORS error».** Под ним может быть 500 от сервера: у ответа с ошибкой просто нет CORS-заголовков.
- **Путать 401 и 403.** 401 — «кто ты?», 403 — «знаю, кто ты, но нельзя».
- **Искать ошибку, когда кука не ушла.** Ошибки нет: браузер молча не приложил куку. Причину видно в DevTools.
- **Считать, что preflight прошёл, раз сервер ответил 204.** Если в ответе нет нужных заголовков, браузер всё равно не отправит основной запрос.

# Algorithms MOC

Начинать с Complexity: остальные заметки опираются на неё.

- [[Complexity]] — Big-O, худший / средний / амортизированный случаи, как считать.
- [[Search]] — линейный и бинарный поиск, поиск по ответу, инварианты границ.
- [[Sorting]] — таблица алгоритмов, граница n log n, стабильность, подводные камни `Array.sort`.
- [[Hash Tables]] — коллизии, load factor, `Map` против `Object`.
- [[Graphs]] — представления, BFS / DFS, Dijkstra / Bellman-Ford, топологическая сортировка.
- [[Greedy]] — когда локальный выбор оптимален, аргумент обмена, контрпримеры.
- [[Dynamic Programming]] — состояние, переход, база; мемоизация против табуляции.

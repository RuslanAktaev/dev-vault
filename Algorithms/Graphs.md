# Graphs

**Граф** — вершины V и рёбра E. Бывает ориентированным или нет, взвешенным или нет. **DAG** — ориентированный граф без циклов.

## Представление
- **Список смежности** — O(V + E) памяти. Стандарт для разреженных графов.
- **Матрица смежности** — O(V²). Проверка ребра за O(1), подходит для плотных графов.

## Обходы — O(V + E)
- **BFS** (очередь) — по уровням. Даёт **кратчайший путь в невзвешенном графе**.
- **DFS** (стек или рекурсия) — вглубь. Поиск циклов, компонент связности, топологическая сортировка.
- Помечай вершину visited **при добавлении в очередь**, а не при извлечении. Иначе дубли.

## Кратчайшие пути
- **Dijkstra** — неотрицательные веса, жадный выбор ближайшей вершины из приоритетной очереди. O((V + E) log V).
- **Bellman-Ford** — допускает отрицательные веса и находит отрицательные циклы. O(V·E), по сути DP.
- В DAG — релаксация в топологическом порядке, O(V + E).

## Топологическая сортировка
Порядок вершин DAG, при котором все рёбра идут «вперёд». **Kahn**: берём вершины с входящей степенью 0 и удаляем их рёбра. Если вершины остались, есть цикл.
Применяется для порядка сборки, разрешения зависимостей, планирования задач.

## Частые ошибки понимания
- Dijkstra на отрицательных рёбрах даёт неверный ответ.
- DFS-рекурсия на большом графе переполняет стек. Нужен итеративный вариант.
- Для поиска цикла в ориентированном графе недостаточно visited: нужны три цвета (white / gray / black), gray = «в текущем пути».

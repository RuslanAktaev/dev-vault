## Известные особенности CLI
- Любая команда возвращает exit 0, даже при ошибке. Поэтому всегда вызывать через `obs`.
- `obsidian help` без аргументов после обновления до 1.13.7 отрабатывает примерно за 2 с (476 строк).
- `rename` при успехе ничего не печатает. `move` требует, чтобы целевая папка существовала. Если в имени папки есть точка (`Next.js/`), в `to=` нужен полный путь файла, иначе будет `Destination file already exists!`.
- Для `.base` нужен `path=` (`file=` не находит базу).
- Открытое модальное окно в Obsidian молча блокирует файловые операции. Проверка: `obs dev:dom selector=".modal-container" total`.
- `\n` в `content=` превращается в перевод строки.
- `property:set … type=list` со значением через запятую пишет **одну строку**, а не список, и заодно переписывает `tags` в блочный вид. Для `related` проще править frontmatter прямо в файле.
- `append` вставляет перед новым текстом пустую строку.

## Особенности UI (сплиты и терминал)
- В контекстном меню файла Obsidian есть только «Открыть в новой вкладке / в области справа / в новом окне» — варианта «снизу/сверху» нет.
- Панель сверху/снизу делается либо перетаскиванием в зону у верхнего/нижнего края **области содержимого**, либо командами `workspace:split-horizontal` (вниз) и `workspace:split-vertical` (вправо). Дефолтных хоткеев у них нет (`hotkeys.json` пустой).
- Панель плагина `terminal` не принимает drop в области содержимого: при перетаскивании на неё видны только зоны влево/вправо от панели вкладок. Поэтому таскать нужно вкладку терминала на заметку, а не наоборот.
- Новая вкладка открывается в той панели, которая сейчас активна. Если активна панель терминала, открытие заметки (из CLI или кликом) заменит терминал — сессия Claude Code оборвётся.
- Лечится закреплением вкладки терминала (правый клик по вкладке → «Закрепить»): проверено, закреплённая вкладка не переиспользуется, заметка открывается отдельной вкладкой. Запасной вариант — звать `obs open ... newtab`; у CLI `open` есть только `newtab`, `paneType=tab|split|window` документирован лишь у `daily`.

# TurboModules и Codegen

**Определение.** Нативный модуль — любой нативный код, открытый для вызова из JS: встроенные в RN (`Alert`, `Linking`, `Appearance`), библиотеки (MMKV, камера, Reanimated) или свои. **TurboModule** — стандарт новой архитектуры, по которому такой модуль описывается, регистрируется и вызывается. **Codegen** генерирует по TS-спеку обвязку между JS и нативом.

В официальном смысле Turbo Native Module = спек + нативный код + интерфейсы от Codegen. В узком смысле иногда так называют сам механизм подключения.

## Свойства TurboModule
- **Типизированный контракт**: несовпадение спека и реализации ломает сборку, а не падает в рантайме.
- **[[JSI]] вместо bridge**: без JSON-сериализации.
- **Ленивая загрузка**: модуль создаётся при первом обращении, а не на старте.
- **Синхронные вызовы возможны**, но блокируют JS-поток.
- **Безопасный доступ к `jsi::Runtime`** (с 0.75): `RCTTurboModuleWithJSIBindings` на iOS, `TurboModuleWithBindings` на Android; `CallInvoker.invokeAsync` — чтобы перейти в JS-поток.

## Что пишется руками, что генерируется
| | Что |
|---|---|
| **Руками** | TS-спек и нативная реализация (Swift/Obj-C, Kotlin/Java, C++) |
| **Codegen** | C++-обвязка и нативные интерфейсы (протокол, абстрактный класс) |
| **Готово в ядре** | JSI и базовые классы `ObjCTurboModule`, `JavaTurboModule` |

Обычный разработчик пишет свой TurboModule редко, чаще использует готовые.

```ts
// NativeLocalStorage.ts — спек; префикс Native обязателен
import type { TurboModule } from 'react-native';
import { TurboModuleRegistry } from 'react-native';

export interface Spec extends TurboModule {
  setItem(value: string, key: string): void;
  getItem(key: string): string | null;
}

export default TurboModuleRegistry.getEnforcing<Spec>('NativeLocalStorage');
```

Регистрация по имени: `TurboModuleRegistry.get` (вернёт `null`, если модуля нет) или `getEnforcing` (бросит ошибку).

## Модули на C++
- **Cxx TurboModule** — модуль целиком на C++: прямой доступ к `jsi::Runtime`, одна логика для обеих платформ.
- **C++-ядро под обычным TurboModule** — частый вариант: MMKV, op-sqlite, quick-crypto, Reanimated.

## Граница JS ↔ натив
- Через спек проходит только **публичная часть**: методы, пропсы, события, команды.
- Всё внутри нативной части — SDK, потоки, БД, кэши, классы, нативные зависимости — обычный нативный код без Codegen и мостов.
- Граница должна быть **узкой**: крупные операции вместо множества мелких вызовов.
- Данные на границе конвертируются, поэтому большие объёмы (картинки, буферы) держат в нативе, а в JS отдают ссылку или результат.

## Codegen
Программа на Node.js (`@react-native/codegen`), шаблонизатор, не ИИ. Запускается автоматически при сборке: на iOS — скриптами при `pod install`, на Android — Gradle-плагином RN.

**Шаги:**
1. Найти спеки по конвенции: префикс `Native` у TurboModule, суффикс `NativeComponent` у Fabric-компонентов, путь из `codegenConfig` в `package.json`.
2. Распарсить TS/Flow в AST.
3. Построить схему — JSON-описание модулей, методов, типов.
4. Подставить схему в шаблоны.

**Выход:**
- C++ (`.h`/`.cpp`), например `NativeXSpecJSI`: принимает `jsi::Value`, приводит типы по сигнатуре, вызывает платформенный метод и упаковывает результат обратно в `jsi::Value`;
- iOS — Obj-C протокол `NativeXSpec`;
- Android — абстрактный Java-класс `NativeXSpec`;
- немного клея на Obj-C++ и JNI;
- для Fabric-компонентов — Props, ComponentDescriptor, ShadowNode, EventEmitter (см. [[Fabric]]).

Лежит в build-директориях (`build/generated/ios`, `build/generated/source/codegen`), не коммитится и пересоздаётся при каждой сборке. Логику модуля или вьюхи Codegen не генерирует.

## Частые ошибки понимания
- **«TurboModule — это библиотека или конкретный модуль».** Это стандарт описания и подключения нативного модуля.
- **«Codegen пишет нативный код за меня».** Только обвязку и интерфейсы. Реализацию пишет разработчик.
- **«Сгенерированный код надо коммитить».** Он пересоздаётся при сборке.
- **«Через спек видно всё нативное».** Только публичный контракт, внутренности остаются обычным нативным кодом.
- **«Раз вызовы дешёвые, можно дёргать натив часто».** Граница всё равно стоит конвертации, лучше крупные операции.

# New Architecture

Замена старого **Bridge** на прямое взаимодействие JS ↔ native через C++. Состав: **JSI + Fabric + TurboModules + Codegen**; рядом обычно называют Hermes — движок по умолчанию, формально отдельная часть. Включена по умолчанию с RN 0.76, поддержку библиотек сверяй с документацией своей версии.

## Что было: Bridge
- JS и native общались **асинхронными батчами JSON-сообщений** через мост.
- Сериализация на каждый вызов, синхронные вызовы невозможны. Все нативные модули инициализировались на старте.
- Layout и измерения были асинхронными → мигания и задержки (например, при измерении view). Синхронно прочитать layout из JS было нельзя.
- Работа делилась между JS-потоком, shadow-потоком (layout) и UI-потоком, их синхронизация давала задержки и мерцание.
- Concurrent-фичи React не работали.

## JSI — JavaScript Interface
Слой на C++, через который JS **держит ссылки на C++-объекты (host objects)** и вызывает их методы напрямую, без сериализации.
- Возможны синхронные вызовы.
- Не привязан к движку: Hermes, JSC.
- Основа для TurboModules и Fabric.

## TurboModules
Новые нативные модули поверх JSI.
- **Ленивая загрузка**: модуль инициализируется при первом обращении → быстрее старт.
- **Codegen**: TS/Flow-спецификация модуля → типобезопасные C++/ObjC/Java-интерфейсы. Контракт JS ↔ native проверяется при сборке.

## Fabric
Новый рендерер, заменил Paper.
- **Shadow tree на C++**, иммутабельное и общее для платформ. Layout считает Yoga до mount.
- Синхронные измерения layout, когда нужно.
- Поддержка concurrent-фич React 18: `startTransition`, Suspense, автоматический батчинг.
- React reconciler тот же, что и в вебе, меняется только хост.

Шаги, Shadow Tree, diff и Yoga подробно — в [[Fabric]].

**Bridgeless mode** — окончательный отказ от моста.

## Частые ошибки понимания
- «JSI делает всё синхронным». Синхронный вызов блокирует JS-поток. Тяжёлую работу по-прежнему надо делать асинхронно.
- Hermes = New Architecture. Нет: это отдельная вещь (движок). JSI просто позволяет подключать разные движки.
- Старые библиотеки «просто работают». Есть interop-слой, но либы без поддержки Fabric/TurboModules — частый источник проблем при миграции.

## Связи
- [[Virtual DOM]] — два хоста для одного reconciler: DOM и нативный shadow tree. Разные модели коммита.
- [[Event Loop]] — асинхронный мост работал как очередь сообщений. JSI позволяет синхронные вызовы прямо из call stack JS.
- [[Fabric]] — рендерер: хост-операции, Shadow Tree, diff, Yoga, mount, цепочка от `setState` до экрана.

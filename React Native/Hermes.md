# Hermes

**Определение.** Hermes — JS-движок от Meta, сделанный под React Native. Написан на C++ и используется в RN по умолчанию. Заменил **JavaScriptCore (JSC)**; V8 и SpiderMonkey в RN по умолчанию никогда не стояли. Hermes только исполняет JS приложения: про UI и натив он ничего не знает.

## Главная идея: AOT вместо JIT
- JS компилируется в байткод (`.hbc`) **заранее, на этапе сборки**, а не парсится на устройстве при запуске.
- **Плюсы:** быстрее старт (TTI), меньше потребление памяти, меньше размер приложения.
- **Минус:** нет JIT, поэтому тяжёлые вычисления на чистом JS могут работать медленнее, чем в движке с JIT.

## Из чего состоит
| Часть | Когда работает | Что делает |
|---|---|---|
| Компилятор | На сборке | JS → байткод |
| VM | В рантайме | Исполняет байткод, GC |
| Реализация [[JSI]] | В рантайме | `HermesRuntime` реализует `jsi::Runtime`, через неё RN встраивает движок |

## Что есть в Hermes «из коробки»
- Сам язык: `Array`, `Promise`, `Map`, `JSON` и т. д.
- JSI и `HermesInternal`.
- **Нет** `fetch`, таймеров и `console` как платформенных API: эту среду собирает RN из полифилов и нативных модулей. Браузерных API (`DOM`, `window`) нет вовсе.
- Что RN регистрирует в рантайме при старте — в [[JSI]].

## Бандл
- **Release:** Metro склеивает и минифицирует JS, Hermes компилирует его в байткод. Файл лежит в приложении: на Android — `assets/index.android.bundle`, на iOS — `main.jsbundle`.
- **Dev:** бандла в приложении нет, Metro раздаёт его по сети.
- **OTA-обновления** (EAS Update, CodePush) возможны именно потому, что JS-бандл — отдельный файл, его можно подменить. Нативный код так обновить нельзя, нужна новая сборка через стор.

## Частые ошибки понимания
- **«Hermes — часть новой архитектуры».** Это отдельный движок, он работает и со старой архитектурой. Новая архитектура держится на [[JSI]], который движок-независим.
- **«Hermes заменил V8».** Заменил JSC.
- **«Hermes всегда быстрее».** Быстрее старт и меньше память, но без JIT тяжёлый чистый JS может быть медленнее.
- **«`fetch` и `setTimeout` — часть движка».** Их добавляет RN поверх движка.
- **«Если Hermes на C++, JSI не нужен».** Движок на C++ ничего не знает о RN. [[JSI]] — интерфейс, через который C++-код RN регистрирует в движке свои функции и объекты и работает с JS-значениями.

## Связи
- [[New Architecture]] — Hermes называют рядом с новой архитектурой, но формально это отдельная часть.
- [[JSI]] — Hermes реализует `jsi::Runtime`, через JSI RN добавляет в движок нативные функции.
